find
Возвращает список активных задач стоматологии.

Описание
Результаты сортируются:

По дате выполнения doWhen — по возрастанию.
По идентификатору задачи — по убыванию.
Поиск по сотруднику
employee_id ищет сотрудника среди исполнителя, автора и врача задачи.
employee_name ищет по имени исполнителя среди врачей и менеджеров.
Если переданы оба параметра, задача должна соответствовать обоим условиям.
Пагинация
По умолчанию возвращается 50 задач на странице. Максимальное значение atPage — 200. Нумерация страниц начинается с 1.

Для выполнения метода необходимо право tasks_read.
